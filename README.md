# bot4stage

بوت الطلاب لأربع مراحل، مع Telegram Mini App، محتوى دراسي واختبارات ومفضلة ودعم ومعلومات فيزيائية ومساعد اختياري.

ابدأ بقراءة [دليل الإصلاحات والنشر](FIXES_AND_DEPLOYMENT_AR.md)، خصوصًا متطلبات ترحيل القاعدة والتحقق من النسخ الاحتياطية.

## أسئلة الاختبار

للمطور والأدمن زر «إدارة الأسئلة» لحذف سؤال مع تأكيد، وفق صلاحيات المرحلة. تدعم الإضافة الاختيارات وصح وخطأ والفراغات، وتعمل الإجابات في البوت وMini App. راجع دليل الإصلاحات لخطوات الإضافة والحذف والتصحيح النصي.

## متابعة حظر البوت

للمطور فقط: زر «من حظر البوت» في لوحة الإدارة، أو الأمر `/blocked_users` في الخاص. تعرض القائمة أسماء ومعرفات المستخدمين والحالة والمرحلة ووقت اكتشافها، مع تمييز الحسابات المحذوفة والحالات القديمة غير المحددة ومن عادوا للتفاعل.

## التشغيل

يتطلب Python 3.11 ومتغيرات API_ID وAPI_HASH وBOT_TOKEN وDEVELOPER_ID. PostgreSQL إلزامي عند `ENVIRONMENT=production`، وSQLite للتطوير المحلي.

```bash
python -m pip install -r requirements.txt
python main.py
```

ضع الإعدادات الخاصة في بيئة الاستضافة أو `.env` محليًا. `.env` و`.env.example` المرفقان قوالب بلا مفاتيح المستخدم، وDocker يستبعد ملفات البيئة الخاصة.

## الاختبار

```bash
python -m unittest discover -s tests -v
```

الاختبارات لا تتصل بتيليجرام. اختبارات PostgreSQL اختيارية على قاعدة فارغة مخصصة للاختبار؛ راجع الدليل قبل ضبط `TEST_POSTGRES_DSN`.

لاختبار تشغيل واجهة الموقع (Node.js 18 أو أحدث):

```bash
npm ci
npm run test:client
```

يشغّل الاختبار الواجهة في DOM مع Telegram SDK وAPI وهميين، ويغطي فتح الصفحات والبحث وأنواع أسئلة الاختبار. تبعيات Node للاختبار فقط.
